## 🛠️ Tuzatilgan Kamchiliklar va Xatolar (Bug Fixes)

1. **Unclosed HTML tag xatosi**: `heroTitle` sarlavhasida ochilgan `<em>` tegi yopilmay qolgani to‘liq to‘g‘rilandi.
2. **Kirill-Lotin chalkashligi**: So‘z o‘yinidagi `"DARAXT"` so‘zida kirillcha `"Х"` harfi ishlatilgani sababli to‘g‘ri javob qabul qilinmas edi — barcha so‘zlar toza lotin alifbosiga o‘tkazildi.
3. **Mobil navigatsiya kamchiligi**: Mobil menyuda "Reyting" va "Do‘kon" tugmalari yo‘q edi — to‘liq 5 ta asosiy bo‘lim bilan boyitildi.
4. **Takroriy hodisalar (Duplicate Event Listeners)**: Profil tugmasi va boshqa tugmalardagi ortiqcha eshituvchilar tozalandi.
5. **Topshiriqlar hisob-kitobi**: Topshiriqlarni olishdagi statik mukofotlar dinamik ob’yektlarga bog‘landi va XP berilishi yo‘lga qo‘yildi.
6. **Responsiv dizayn**: Telefonlar (320px–480px), planshetlar va kompyuter monitorlarida to‘liq moslashuvchan (responsive) holatga keltirildi.
